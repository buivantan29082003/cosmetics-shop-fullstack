# Cosmetics Shop – Full-Stack E-commerce Website

A full-stack e-commerce web application for selling cosmetics, developed using Spring Boot and ReactJS. The project focuses on building RESTful APIs, implementing authentication and authorization, managing product and order data, and integrating external services.

## About Me

Through personal projects, I have gained experience in building RESTful APIs, developing database-driven applications, and integrating backend services.

## Key Features

- **User Authentication and Authorization:** Implement authentication and access control using Spring Security and JWT.
- **Product Management:** Manage cosmetic products and related information.
- **Shopping and Order Management:** Support shopping and order-related workflows.
- **Database Integration:** Use Spring Data JPA and Hibernate to interact with relational database data.
- **RESTful APIs:** Develop backend endpoints for communication between the frontend and backend.
- **Real-Time Communication:** Use WebSocket for supported real-time features.
- **Image Management:** Integrate Cloudinary for image storage and management.
- **External Service Integration:** Explore integrations with payment and delivery services.

## Project Structure

The project consists of two main parts:

- **Backend:** Spring Boot application providing RESTful APIs, business logic, security, and database access.
- **Frontend:** ReactJS application providing the user interface and communicating with backend APIs.

## Getting Started

### Prerequisites

- Java 17 or compatible JDK
- Node.js and npm
- MySQL
- Redis (if required by the backend configuration)
- Maven, or the Maven Wrapper included in the project

### Installation

1. Clone the repository:

2. Configure the backend database connection and other required environment variables.

3. Start the Spring Boot backend using the Maven Wrapper or your configured Maven installation.

4. Navigate to the frontend directory, install dependencies, and start the ReactJS development server.

> Note: Update the commands and directory paths above to match the actual backend and frontend structure of the repository. Configure credentials and API keys locally; do not commit secrets to GitHub.
